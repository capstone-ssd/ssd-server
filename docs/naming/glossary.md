# Glossary

## 목적
- SSD에서 사용하는 핵심 도메인 용어를 고정한다.
- 같은 개념을 다른 단어로 혼용하지 않도록 기준을 제공한다.

## 작성 규칙
- `Term`: 공식 용어
- `Definition`: SSD 문맥에서의 정확한 의미
- `Allowed aliases`: 문맥상 허용 가능한 보조 표현
- `Disallowed aliases`: 혼동을 유발해 지양하는 표현
- `Follow-up issue`: 실제 rename 또는 구조 반영 이슈 번호
