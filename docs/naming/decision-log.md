# Naming Decision Log

## 목적
- 용어 충돌, 허용 예외, naming 방향 결정의 근거를 기록한다.
- 같은 논의를 반복하지 않도록 결정 이력을 남긴다.

## 기록 규칙
- `Date`: 결정 날짜
- `Issue/PR`: 관련 이슈 또는 PR
- `Decision`: 무엇을 어떻게 정했는지
- `Reason`: 왜 그렇게 정했는지
- `Impact`: 어떤 후속 변경에 영향을 주는지
