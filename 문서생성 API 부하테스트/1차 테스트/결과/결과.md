## 테스트 시나리오
### 1. Smoke
- 설정: `3 VU`, `1분`
- 목적: 인증/연결/응답 구조 검증

### 2. Payload Curve
- 설정: `5 VU`
- 구간: `small -> medium -> large -> xlarge`
- 각 구간 유지 시간: `1분`
- 목적: payload 크기 증가에 따른 응답시간 변화 확인

### 3. Target
- 설정: `10 -> 50 -> 100 -> 150 VU`
- 구간: `30초 -> 45초 -> 45초 -> 2분 -> 감쇠 30초`
- 목적: 150 VU 러프 검증

1. 현재 러프 테스트 범위에서는 `POST /api/v1/documents`가 150 VU 구간을 안정적으로 처리했다.

3. payload-curve에서 단일 outlier는 있었지만, 구간별 p95는 안정적이었다.
4. 다음 단계에서는 `stress`, 더 긴 유지 시간, 앱/모니터링 분리 환경에서 재검증이 필요하다.
